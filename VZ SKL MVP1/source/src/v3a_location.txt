=== vocabulary location
title: Location vocabulary
subject: Location
description: Controlled values for the United States jurisdictions where worksite clients operate, work arrangements, and address types.
scope: Jurisdictions carry ISO 3166 codes in skos:notation. The federal and state jurisdictions are siblings under one value set, because skos:broader is used only for classification; the legal containment of a state within the United States is modeled in the ontology with located in.
standard: ISO 3166-1 and ISO 3166-2 codes; LKIF-Core jurisdiction.
datatype: country-code | Country code | A datatype for two-letter country codes defined by ISO 3166-1.
datatype: country-subdivision-code | Country subdivision code | A datatype for country subdivision codes defined by ISO 3166-2.
---

Work arrangement :: A controlled value set for where a worker regularly performs work. || prefix: work-arrangement
  Onsite :: A work arrangement in which the worker works at an employer or client site. || alt: In office; On premises
  Remote :: A work arrangement in which the worker works away from employer and client sites. || alt: Telework; Work from home
  Hybrid :: A work arrangement in which the worker splits time between onsite and remote work.
Address type :: A controlled value set for the purpose of a postal address. || prefix: address-type
  Physical address :: An address type for where a party or site is located. || alt: Street address; Residence address
  Mailing address :: An address type for where correspondence is delivered.
  Worksite address :: An address type for where workers perform work for a client. || alt: Work location address
  Billing address :: An address type for where invoices are sent.
  Registered address :: An address type for a legal entity's official registered office. || alt: Registered office
