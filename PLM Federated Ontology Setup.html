How the scoring model binds to the semantic layer

Every standard is a federated OWL module imported into HSGA

The Defect & Risk Scoring Model doesn't hard-code rules. Each discipline, standard, and governance regime — 15288, 42010, 29148, 62304, ICH Q8–Q12, GxP, ISO 42001 — is its own ontology module that owl:imports HSGA core, asserts its mandate as an OWL axiom and a SHACL shape, and declares the defect it emits. A conformance failure is then a proven defect, not an inferred one — and the whole thing carries a determinism ratio.

Deterministic — SHACL / OWL (decidable) Inferred — LLM judgment (MTBH-gated) Regulated regime — higher impact weight

C

Anatomy of one module — ISO/IEC/IEEE 42010

The mandate "an architecture description shall frame at least one viewpoint" becomes both an OWL restriction (entailment-decidable) and a SHACL shape (validation-decidable) that declares the defect it produces.

# (a) import core · (b) specialise the artifact class
std4:ArchitectureDescription a owl:Class ;
    rdfs:subClassOf hsga:LifecycleArtifact .

# (c-OWL) entailment-decidable mandate
std4:ArchitectureDescription rdfs:subClassOf
    [ a owl:Restriction ; owl:onProperty std4:hasViewpoint ;
      owl:minCardinality 1 ] .

# (c-SHACL) validation-decidable mandate + (d) defect declaration
std4:ViewpointConstraint a sh:PropertyShape ;
    sh:path std4:hasViewpoint ;
    sh:minCount 1 ;
    sh:message "ISO/IEC/IEEE 42010 §5.5: frames no viewpoint…" ;
    hsga:producesDefectClass std4:MissingArchitectureViewpoint ;
    hsga:defectSeverity hsga:Major ;
    hsga:emitsDerivation hsga:SHACL ;      # <-- PROVEN, not inferred
    hsga:moduleRef std4:Module .

The four hsga: annotations on the shape are what make a raw sh:ValidationResult self-compile into a governed hsga:Defect — see the CONSTRUCT in step 4 below.

# Step 4 — the CONSTRUCT that turns a validation result into a governed defect
CONSTRUCT { ?defect a hsga:Defect ; hsga:onArtifact ?focus ;
    hsga:defectClass ?dclass ; hsga:severity ?sev ;
    hsga:derivation ?deriv ; hsga:raisedByModule ?module . }
WHERE {
  ?result a sh:ValidationResult ; sh:focusNode ?focus ; sh:sourceShape ?shape .
  ?shape hsga:producesDefectClass ?dclass ; hsga:defectSeverity ?sev ;
         hsga:emitsDerivation ?deriv ; hsga:moduleRef ?module . }
